# Wake Mini 1.6.0

## Обновление из меню
В трее появились «Проверить обновления…» и «Вернуть предыдущую версию…». Проверка запускается вручную и предлагает установить последний обычный релиз GitHub. Архив проверяется по SHA-256, EXE — по номеру версии. Заменяется только EXE: wake.key, JSON настройки и расширение не затрагиваются. Перед заменой сохраняется предыдущий EXE. Если новая версия сразу завершилась, установщик возвращает старую. Неудачная замена занятого файла сохраняет рабочую версию; при сообщении о занятом EXE закройте Chrome и повторите обновление. Помощник должен находиться в доступной для записи папке пользователя. Возврат на более старую версию не откатывает настройки.

Впервые 1.6.0 нужно поставить вручную: завершите помощник через трей, замените WakeMiniAgent.exe в прежней папке, сохранив ключ и JSON, затем запустите. Следующие версии можно устанавливать через меню.

## Вернуть звук на телевизор
В настройках «Разговор с ChatGPT / FreeBuds» выберите выход телевизора LG / HDMI / NVIDIA High Definition Audio и сохраните. В трее и настройках есть кнопка «Вернуть звук на телевизор». Она завершает голос ChatGPT при наличии связи с расширением, переключает вывод Windows на выбранный HDMI и LG на динамики. Наушники не удаляются из Bluetooth и остаются сопряжёнными. Микрофон Windows не переключается.

Для Алисы обновите существующую облачную функцию архивом WakeMini-Alice-Cloud-1.6.0.zip, сохранив переменные окружения и адрес. Обновите список устройств навыка в «Доме с Алисой». Создайте сценарий с фразой «Верни звук на телевизор» и действием «Звук компьютера на телевизор» → включить. Сначала обновите помощник, затем облако.

Android и расширение Chrome не менялись. Сценарий «Запусти Атлас» остаётся прежним.

## Проверка
GitHub Actions проверяет установку/откат/занятый EXE на Windows с временными файлами, сборку, протоколы, ТВ, облако и расширение. На реальном ПК проверьте выбор HDMI и динамиков LG, затем повторный запуск Атласа. Программы с закреплённым собственным аудиовыходом могут потребовать отдельного выбора HDMI в настройках Windows/игры.
