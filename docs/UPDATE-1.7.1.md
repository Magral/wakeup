# Wake Mini 1.7.1 — Big Picture и обновления игр

Перед запуском выбранной игры помощник явно отправляет Steam команду перехода в Big Picture, включая уже работающий обычный Steam. Затем отправляет запрос игры. Steam должен быть авторизован; готовность интерфейса Big Picture самим клиентом не подтверждается через публичный протокол.

После запроса помощник наблюдает состояние appmanifest и процесс игры. Если обнаружено обновление, ждёт до 20 минут. После трёх стабильных проверок завершения обновления повторно отправляет запуск один раз, предварительно проверяя, не запустил ли Steam игру самостоятельно. Быстрые обновления учитываются по изменению buildid. Медленная загрузка игры без признаков обновления не вызывает повторных команд. appmanifest только читается, настройки Steam и автообновления не меняются.

Во время ожидания обновления остаются доступны команды Работа/Игры, HDMI и Атлас. Текущая команда запуска наблюдается до результата; новая облачная команда будет проверена после завершения текущей. По истечении 20 минут автоматическое ожидание заканчивается. При перезапуске помощника незавершённая команда не выполняется снова.

Диагностика Steam различает ожидание обновления, повторный запрос, подтверждённый запуск и неподтверждённый запрос. launch_requested остаётся совместимым кодом облака и не означает гарантированного запуска.

## Обновление
Из трея нажмите «Проверить обновления…». Для ручной установки завершите помощник через трей и замените только WakeMiniAgent.exe, сохранив ключ и JSON. Версия — 1.7.1.0. Облако остаётся 1.7.0; Android и расширение Chrome не менялись, обновлять их не требуется. Бакет и настройки навыка Стим сохраняются.

## Проверка на вашем ПК
Проверьте запуск игры из обычного Steam, затем запуск игры, которой требуется обновление. После обновления она должна получить один повторный запрос запуска, если сама ещё не запустилась. Steam может потребовать ручной выбор варианта запуска, вход, принятие соглашения, UAC или действия в стороннем лаунчере — такие окна помощник не подтверждает автоматически. Сообщите строку диагностики, если запуск всё ещё блокируется.

GitHub Actions проверяет последовательности обновления/повтора/автозапуска/отмены и прежние тесты Steam, Windows, протокола, ТВ и облака. Сам Steam и реальная загрузка игры проверяются на домашнем ПК.
