# Wake Mini 1.7.4 — HDMI следует питанию Windows

- Новый вход в Windows (после включения/перезагрузки) и выход ПК из сна/гибернации выбирают HDMI 1 (ПК), при необходимости включая LG через существующий WoL.
- Перед сном и при подтверждённом завершении работы/перезагрузке Windows выбирается HDMI 2 (приставка). Способ запроса — Алиса, приложение, меню Пуск, клавиатура, кнопка питания с действием «сон» — не имеет значения: обрабатывается само событие Windows.
- Закрытие/обновление помощника, обычный выход из учётной записи и отменённое завершение работы не переключают HDMI 2.
- Дублирующие уведомления пробуждения не создают повторных переключений. Новое событие сна отменяет незавершённую старую команду HDMI 1. Ручное переключение входа после пробуждения сохраняется: фоновая подготовка соединения не выбирает вход сама по себе.

## Настройка и обновление

Обновите **только Windows-помощник до 1.7.4.0**: трей → «Проверить обновления…». При ручной замене завершите помощник через трей и замените только WakeMiniAgent.exe, сохранив wake.key и JSON. Android остаётся 1.7.3, облако — 1.7.2, расширение Chrome и сценарии Алисы не менялись. APK 1.7.3 добавлен к релизу для удобства установки, это не новое обновление Android.

В настройках LG новая опция «Следовать питанию ПК: запуск / пробуждение → HDMI 1, сон / выключение → HDMI 2» включена по умолчанию. Используются уже сохранённые IP, ключ сопряжения и сертификат. Первый запуск обновления в уже открытой сессии сохраняет текущий вход ТВ; проверять HDMI 1 нужно после следующего запуска Windows или пробуждения. Перезапуски/обновления помощника в той же сессии повторно HDMI 1 не выбирают. Служебный файл wake-power-session.txt хранит только хеш идентификатора текущего входа, не пароль или ключ.

Старые файлы настроек получают включённую опцию при чтении; повторное сопряжение не требуется. Если отключить синхронизацию, прежняя отдельная настройка включения ТВ при запуске помощника остаётся доступной.

Помощник должен работать в трее и быть включён в автозагрузку. При холодном старте переключение выполняется после запуска помощника в пользовательской сессии Windows, не на этапе BIOS/экрана входа. До входа в пользовательскую сессию этот помощник не работает как системная служба.

## Ограничение событий питания

Перед сном Windows даёт приложению приблизительно две секунды. Помощник заранее держит готовое локальное WebSocket-соединение LG, использует сохранённый ключ и проверку сертификата; при уведомлении ждёт не более 1.6 секунды. Если готовое соединение пропало, выполняется одна попытка подключения в оставшемся лимите. Для HDMI 2 телевизор не пробуждается и длинные повторы не запускаются. Неудача записывается в диагностику и не препятствует сну/выключению Windows.

Никакая программа на выключаемом ПК не гарантирует сетевую команду при обрыве питания, принудительном завершении процесса, отключённой сети или недоступном телевизоре. При штатном переходе задача отправляется по событию Windows; фактический результат надо проверить на вашем ПК/ТВ.

## Проверка дома

1. Включите ПК обычной кнопкой: после входа и запуска помощника LG должен выбрать HDMI 1.
2. Выберите «Пуск → Спящий режим»: ТВ должен выбрать HDMI 2. Разбудите ПК геймпадом/клавиатурой/кнопкой/WoL — HDMI 1.
3. Выберите «Пуск → Завершение работы»: перед завершением ТВ должен выбрать HDMI 2.
4. Повторите сон и выключение через Алису; затем проверьте перезагрузку: HDMI 2 при завершении и HDMI 1 после старта.
5. В диагностике ищите «Питание Windows: ТВ подтвердил HDMI …». Тайм-аут/отказ LG отмечается отдельно, без ложного подтверждения.

Автотесты проверяют последовательность событий, отмену задержавшейся команды, тайм-ауты и повтор после неудачи; реальное скрытое окно Windows получает безопасные имитированные сообщения без выключения тестового ПК. Тест LG использует настоящее TLS/WebSocket-соединение с макетом ТВ и проверяет несколько команд в одном сопряжённом сеансе без WoL. Работа конкретного ПК при фактическом засыпании/выключении остаётся домашней проверкой.
