# Wake Mini 1.5.6 — игровой режим и NVIDIA Overlay

Игровой режим больше не отправляет команду сворачивания всем видимым окнам подряд. Сворачиваются обычные окна приложений с кнопкой минимизации. Служебные, прозрачные и неактивируемые окна, а также процессы NVIDIA и Steam пропускаются. Это устраняет обнаруженный в коде путь, который мог сворачивать статистику NVIDIA и оставлять плашку Overlay DT.

## Обновление
Завершите Wake Mini через значок в трее. Замените только WakeMiniAgent.exe из архива в прежней папке и запустите. Сохраните wake.key и JSON настройки. Версия помощника — 1.5.6.0. Android, облачную функцию и расширение Chrome обновлять не нужно.

## Проверка
Автотесты проверяют отбор обычных окон, служебных HUD и процессов NVIDIA/Steam. Самодостаточная сборка Windows x64 успешно собрана через .NET 8. Автотесты протокола, ТВ, расширения и облачной функции прошли. Тест голосового моста в этой среде ограничен запретом локальных каналов связи. Перед публикацией релиза GitHub Actions выполняет сборку Windows и интеграционные проверки помощника. Проверку статистики на реальном ПК с NVIDIA нужно выполнить после установки: включить статистику, вызвать игровой режим через Алису, затем проверить повторный вызов и возврат в рабочий режим. Окна обычных приложений должны сворачиваться, статистика — оставаться. Ранее зависший оверлей перед проверкой один раз выключите и включите в NVIDIA App.
