# Wake Mini 1.5.0 — проверочная сборка

Исправления и автоматизация собраны вместе. Проверки на реальном LG C5 OLED и HUAWEI FreeBuds SE 2 выполняются после установки: CI не заменяет проверку драйвера Bluetooth, разрешений webOS и Chrome на вашем ПК.

## Что изменено

- Повтор временно неудавшейся проверки аккаунта Яндекс в ограниченном бюджете ожидания. Неверная авторизация не допускается; просроченный кэш не используется.
- Запоздалый дубликат подписанного ответа ONLINE не перекрывает подтверждение команды.
- Повтор UDP-команды возвращает сохранённое подтверждение без повторного выполнения. Пакет с другого адреса не расходует правильный одноразовый запрос. Ограничен размер пакетов и число ожидающих проверок связи.
- Профили Работа и Игры могут переключать Chrome и Steam Big Picture. Кино сохраняет обычный запуск программы. Названия и автозапуск ПК не меняются.
- Новая виртуальная кнопка «Разговор с ChatGPT»: LG переключается на динамики; помощник проверяет подтверждение, запрашивает подключение выбранных аудиоустройств Windows, проверяет доступность звука и микрофона, выбирает их системными устройствами и отправляет Chrome запрос на открытие https://chatgpt.com/.

## Установка — когда решите проверить сборку

1. Завершите помощник через меню значка в трее. Сохраните прежний EXE для отката.
2. Распакуйте новый EXE и THIRD-PARTY-NOTICES.txt в прежнюю папку. Сохраните wake.key, wake-actions.json и wake-tv.json. Новый ключ создавать не нужно. Запустите EXE.
3. В редакторе существующей функции wakemini-alice загрузите вложенный WakeMini-Alice-Cloud-1.5.0.zip. Python 3.12, main.handler. Сохраните все прежние переменные окружения. Создайте новую версию.
4. Обновите устройства сервиса Wake Mini в Доме с Алисой. Появится «Разговор с ChatGPT».

Android APK для этих изменений обновлять не требуется.

## Сначала Работа, затем Игры

В меню помощника откройте «Профили: Работа / Игры / Кино». Нажмите «Заполнить Chrome и Steam автоматически» либо выберите установленный chrome.exe для Работы и steam.exe для Игр вручную. Включите переключение окон и сохраните.

Работа активирует существующее окно Chrome или запускает браузер. Игры отправляют Steam команду steam://open/bigpicture и пытаются вывести окно Steam вперёд. Вкладки браузера, Steam и игры не закрываются. Windows может ограничивать перевод окна на передний план; результат будет в диагностике, принудительного ввода клавиш нет.

Для удобных голосовых фраз создайте сценарии: например «Открой браузер» → «Рабочий режим компьютера: Включить»; «Верни Steam» → «Игровой режим компьютера: Включить». Можно указать несколько фраз для одного сценария.

## Разговор с ChatGPT и наушники

1. В меню помощника откройте «Разговор с ChatGPT / FreeBuds». Укажите Chrome, точный выход FreeBuds SE 2 и их микрофон. Если устройств нет в списке, подключите наушники к Windows вручную и откройте окно снова.
2. В настройках LG выполните повторное сопряжение и подтвердите запрос на телевизоре, если старый ключ не имеет разрешения CONTROL_AUDIO.
3. Нажмите «Проверить LG: переключить на динамики». Проверка меняет вывод звука LG и ожидает подтверждения tv_speaker. При отказе дальнейшее подключение наушников не запускается.
4. Разрешите подготовку по команде Алисы, сохраните настройки и нажмите «Подготовить разговор сейчас». В окне виден каждый этап и итог.
5. В Chrome разрешите микрофон и выберите системный микрофон или FreeBuds. Нажмите кнопку голосового разговора на странице ChatGPT. Автоматический запуск голосового сеанса не реализован.
6. После успешной ручной проверки создайте сценарий «Хочу поговорить с ChatGPT» → «Разговор с ChatGPT: Включить».

Алиса подтверждает приём фоновой задачи, а не готовность всей цепочки. Итог подготовки отображается в помощнике и его диагностике. Повторный запрос во время подготовки отклоняется, а операция может быть остановлена кнопкой.

Ограничения: FreeBuds SE 2 имеют одно активное соединение. Переключение с ТВ требует подтверждённого освобождения подключения. Запрос драйверу Windows на подключение сам по себе не означает успех; помощник ждёт активного выхода и микрофона до 20 секунд. Доступность устройства не доказывает реальный захват микрофона Chrome: это проверяется разговором на ПК. На некоторых драйверах запрос подключения может не поддерживаться. Выбор системных устройств использует совместимый интерфейс PolicyConfig; при ошибке помощник сообщает о ней. Приложения с собственным выбором звука могут не следовать системной настройке.

Возврат наушников к ТВ пока вручную. Отмена или ошибка не откатывают уже выполненное переключение LG на динамики. Чужие Bluetooth-устройства не отключаются; сопряжения не удаляются, адаптер не перезапускается. Автопереключение при извлечении из кейса не включено, чтобы не перехватывать обычное прослушивание ТВ.

## Откат

Завершите новый помощник и верните прежний EXE. В Yandex Cloud переключитесь на предыдущую версию функции. Существующие ключи и настройки сохранены; настройки разговора лежат отдельно в wake-chat.json. При необходимости вручную верните звуковые устройства в Windows и подключите FreeBuds к LG.
