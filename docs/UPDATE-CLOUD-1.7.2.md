# Wake Mini — облачная функция 1.7.2

## Что изменилось

Общий поиск по приблизительному русскому и английскому звучанию названий всей
синхронизированной библиотеки Steam. Неточные совпадения требуют подтверждения;
подтверждённые варианты запоминаются. Поддерживаются командные слова и номера
продолжений. Ошибка поиска больше не утверждает, что игра не установлена.

## Установка

1. Откройте существующую функцию Wake Mini в Yandex Cloud → «Редактор».
2. Создайте новую версию из архива WakeMini-Alice-Cloud-1.7.2.zip.
3. Сохраните прежние переменные окружения, включая STEAM_BUCKET, STEAM_SKILL_ID,
   AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY и настройки действующей интеграции.
   Не заменяйте их значениями из environment.example.json.
4. Точка входа остаётся main.handler, среда Python 3.12. Сохраните прежние
   настройки функции. requirements.txt содержит зависимость boto3.
5. Дождитесь успешного создания версии и убедитесь, что она активна.
6. Откройте навык привычной работающей фразой и назовите игру по-русски.
   При первом приблизительном совпадении подтвердите название. Повторите запрос:
   сохранённый вариант должен распознаться как дополнительное название.

Windows-помощник, бакет, ключи, идентификатор навыка и настройки связки аккаунтов
менять не требуется. Фраза открытия навыка этим обновлением не изменяется.
Если новой игры нет в каталоге, обновите список Steam в помощнике.

Для отката активируйте предыдущую версию функции. Дополнительные варианты
сохраняются отдельным объектом и не меняют каталог или настройки помощника.

## Проверено

43 локальных теста облачного обработчика: поиск, уточнения, запоминание,
авторизация, подписи и очередь. Голосовой ввод Алисы и запуск игры на домашнем ПК
потребуют проверки после установки. Произвольные смысловые переводы названий
автоматически не угадываются; для них доступна переменная STEAM_ALIASES.
