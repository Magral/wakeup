# Wake Mini 1.5.5

## Что изменилось
- Игровой режим сворачивает окна остальных приложений и запускает Steam Big Picture. Программы не закрываются.
- «Работа» выходит из Big Picture, сворачивает Steam и открывает Chrome.
- «Запусти Атлас» запускает Chrome свёрнутым, если связи с расширением ещё нет, подключает наушники и включает голос ChatGPT.
- При повторном запуске готовые наушники не переподключаются и телевизору не отправляется повторная команда переключения звука. Существующая вкладка ChatGPT используется повторно; завершённый голосовой режим запускается снова, активный не выключается.
- Режим «Кино» удалён.

## Что обновить
1. Завершите Wake Mini через значок в трее. Из WakeMini-1.5.5.zip замените WakeMiniAgent.exe в прежней папке. Сохраните wake.key и все JSON настройки. Запустите помощник; версия должна быть 1.5.5.0.
2. Если расширение Wake Mini Voice уже установлено из архива 1.5.4, обновлять его не нужно: код расширения не менялся. При переходе с более старых версий замените файлы папки chrome-voice-extension из архива и нажмите «Обновить» на chrome://extensions. Не удаляйте расширение.
3. Облачная функция остаётся версии 1.5.4. Если она уже установлена, повторно обновлять её не нужно. При переходе с 1.5.3 или старше загрузите вложенный WakeMini-Alice-Cloud-1.5.4.zip в существующую функцию, сохранив переменные окружения; обновите устройства навыка.
4. Android не менялся, переустанавливать приложение не нужно. Сценарий «Запусти Атлас» → «Разговор с ChatGPT» → включить остаётся прежним.

Для первого запуска голоса один раз войдите в ChatGPT в Chrome, разрешите микрофон, установите расширение и зарегистрируйте связь с ним кнопкой в настройках помощника. Включите фоновый голос и выберите выход и микрофон FreeBuds. Далее Chrome можно закрыть.

## Проверка
Включите игровой режим с несколькими открытыми окнами. Затем запустите «Атлас», завершите разговор и вызовите «Атлас» повторно.
GitHub Actions проверяет сборку Windows, UDP, облачный обработчик, последовательность подготовки и расширение. Bluetooth, фокус окон и голос нужно дополнительно проверить на вашем ПК.
