# Wake Mini 1.5.1 — проверочная сборка фонового голоса

Включает исправления связи с Алисой, профили Работа / Игры / Кино и подготовку FreeBuds из 1.5.0. Добавлено расширение Chrome: запуск и завершение голосового разговора ChatGPT по явной команде. API-ключ не требуется; используются ваш аккаунт и его действующие лимиты.

## Обновление

1. Завершите помощник через трей. Сохраните прежний EXE для отката. Замените WakeMiniAgent.exe в прежней папке; сохраните wake.key, wake-actions.json, wake-tv.json и wake-chat.json. Запустите помощник.
2. В существующей облачной функции загрузите WakeMini-Alice-Cloud-1.5.1.zip, сохранив все переменные окружения; обработчик main.handler. Создайте версию и обновите устройства в Доме с Алисой.
3. Распакуйте chrome-voice-extension в постоянную папку. В Chrome откройте chrome://extensions, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите эту папку. ID должен быть ibfpcecljojcgaekclilbdgpohcigpgh.
4. В помощнике откройте «Разговор с ChatGPT / FreeBuds…» и нажмите «Подключить помощник к расширению Chrome». Регистрация выполняется для текущего пользователя без прав администратора. Chrome и помощник должны работать под одним пользователем. После перемещения EXE повторите регистрацию.
5. Один раз откройте https://chatgpt.com, войдите в аккаунт, разрешите микрофон и проверьте разговор вручную. Выберите в Chrome микрофон FreeBuds или системный микрофон. Оставьте одну вкладку ChatGPT, затем сверните Chrome.
6. В настройках помощника включите «Запускать голос ChatGPT в фоне через расширение Chrome», проверьте выход и микрофон FreeBuds, сохраните. Нажмите «Подготовить разговор сейчас» и проверьте результат в диагностике.
7. Создайте сценарии Алисы: «Хочу поговорить» → «Разговор с ChatGPT: Включить»; «Закончи разговор» → «Разговор с ChatGPT: Выключить». Названия фраз можно выбрать свои.

## Как работает

LG C5 переключается на динамики и подтверждает освобождение Bluetooth; Windows подключает FreeBuds и выбирает звук и микрофон; расширение нажимает подписанную кнопку голосового режима в вкладке ChatGPT. Фоновый режим не вызывает переключение окон Windows и не активирует вкладку Chrome. Chrome необходимо оставить запущенным. Закрытый Chrome автоматически не запускается, чтобы не перехватить фокус игры.

Повтор запуска при уже открытом голосовом интерфейсе не завершает разговор. Кнопка диктовки не используется. При нескольких неизвестных вкладках, неподходящих подписях кнопок или отсутствии подтверждения помощник показывает ошибку. Отменённая либо просроченная команда не начинает новый разговор позже. Завершение относится к вкладке, выбранной расширением. Отмена подготовки после нажатия запуска пытается завершить появившийся голосовой интерфейс; результат остановки требует подтверждения интерфейсом.

## Проверка на вашем ПК

Это автоматизация интерфейса ChatGPT, а не официальный API голосового управления. Изменения страницы, запрос разрешения, язык интерфейса, лимиты аккаунта, сон вкладки или ограничения браузера могут мешать запуску. Подтверждение голосового интерфейса не доказывает, что звук слышен: первая проверка нужна с вашей игрой, LG и FreeBuds. Алиса подтверждает приём задачи; подробный итог находится в помощнике. Успех фонового разговора на вашем оборудовании ещё не подтверждён.

Переключение наушников обратно на ТВ пока вручную. Отмена не откатывает уже переключённый вывод LG. Звук в игре может измениться из-за выбора системных устройств; игры с собственным выбранным выходом могут не следовать настройке Windows. APK обновлять не требуется.

## Откат и удаление

Отключите фоновый режим, верните прежний EXE и предыдущую версию облачной функции. Настройки и ключ сохраняются. Удалите расширение в chrome://extensions. Для удаления регистрации можно удалить ключ HKCU\Software\Google\Chrome\NativeMessagingHosts\ru.wakemini.voice и файл wakemini-voice-host.json. Наушники и звук Windows при необходимости верните вручную.

Документация транспорта: https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging
