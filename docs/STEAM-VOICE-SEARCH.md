# Поиск игр по голосовому названию

Облачный обработчик сопоставляет запрос с синхронизированным каталогом Steam:
точное название, настроенные дополнительные названия, похожий текст и приблизительное
звучание английского названия, произнесённого по-русски. Отдельный список новых игр
или знания нейросети для этого не нужны.

Например, «дредмо», «дредмор», «дредмур» предлагаются как Dreadmoor;
«скайрим» — Skyrim; «халф лайф» — Half-Life. Это общие правила, без исключений
для этих игр. Поддерживаются командные слова («пожалуйста, запусти игру …»),
сокращения из начальных букв, арабские и римские номера продолжений II–X.

Приблизительное совпадение всегда требует подтверждения. Если кандидатов несколько,
Алиса предлагает выбор номером. «Нет» сбрасывает предложение, «стоп» отменяет запуск.
Подтверждённый вариант названия сохраняется в существующем приватном бакете в
`wakemini-steam/spoken-aliases.json` и затем распознаётся как дополнительное название.
Варианты сохраняются только после подтверждения или выбора игры, а не по догадке.
Совпадение одного варианта у нескольких игр снова требует выбора.

Память ограничена 128 играми и 8 вариантами до 128 символов на игру. Настроенная
переменная STEAM_ALIASES продолжает работать. Для сброса выученных вариантов удалите
только объект spoken-aliases.json; настройки, каталог и очередь запусков сохраняются.

Это приблизительное сопоставление произношения, а не универсальный переводчик:
смысловые переводы и произвольные прозвища, не похожие на название, задаются через
STEAM_ALIASES. Для необычного английского произношения может потребоваться другой
вариант названия. Установленные недавно игры должны попасть в синхронизированный каталог.

Изменения находятся в облачной функции. Нужно обновить её код, сохранив переменные
окружения; Windows-помощник обновлять для поиска не требуется. Фразу открытия навыка
сама функция не контролирует: до открытия навыка запрос в этот код не поступает.

Автотесты проверяют несколько разных игр без настроенных вариантов, номера продолжений,
подтверждение, отказ, выбор из нескольких игр, сохранение вариантов между диалогами,
ограничение памяти, неизвестные названия и прежнюю авторизацию/подписи/очередь.
Распознавание реального голоса Алисой и запуск дома требуют отдельной проверки.
