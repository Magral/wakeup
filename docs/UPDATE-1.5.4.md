# Wake Mini 1.5.4

Сборка содержит Windows-помощник 1.5.4.0, облачную функцию 1.5.4 и расширение Wake Mini Voice. Android-приложение не менялось.

## Обновление Windows

1. Щёлкните правой кнопкой по значку Wake Mini в трее и выберите «Выход».
2. Распакуйте `WakeMini-1.5.4.zip` и замените только `WakeMiniAgent.exe`.
3. Оставьте рядом прежние `wake.key`, `wake-actions.json`, `wake-tv.json` и `wake-chat.json`. Запустите помощник.

В «Профили запуска» включите переключение окон и проверьте пути Chrome и Steam. Режим «Работа» закрывает Big Picture по команде Steam, сворачивает Steam и выводит Chrome вперёд. «Игры» сворачивает Chrome и возвращает Steam в Big Picture. Приложения не завершаются.

## Обновление облака и Алисы

1. В Yandex Cloud загрузите `WakeMini-Alice-Cloud-1.5.4.zip` как новую версию текущей функции. Сохраните существующие переменные окружения и параметры функции.
2. В приложении «Дом с Алисой» обновите список устройств навыка. Устройство «Кино на компьютере» удалено.
3. Создайте сценарий: голосовая фраза **«Запусти Атлас»**, действие **«Разговор с ChatGPT» → включить**.

## Первый запуск голоса ChatGPT

В настройках Wake Mini разрешите команду Алисы, включите фоновый голос, выберите FreeBuds как устройство вывода и микрофон. Нажмите «Подключить помощник к расширению Chrome», затем установите папку `chrome-voice-extension` из архива через `chrome://extensions` (режим разработчика → «Загрузить распакованное расширение»).

Один раз войдите в ChatGPT в Chrome и разрешите сайту доступ к микрофону. После этого Chrome можно закрывать: по команде Алисы помощник запустит его свёрнутым, подключит FreeBuds и включит голосовой режим через расширение. ПК должен быть включён, а Wake Mini — работать в трее.

Проверить результат можно в окне диагностики Wake Mini: строка ChatGPT должна сообщить, что интерфейс подтвердил голосовой режим. Алиса сообщает о приёме команды сразу; итог каждого шага записывается в журнал помощника.

## Файлы и проверка

В архиве сборки лежит `WakeMini-Alice-Cloud-1.5.4.zip`; отдельный ZIP облачной функции также публикуется рядом с основным архивом. Файл `SHA256SUMS.txt` содержит контрольную сумму основного ZIP.

GitHub Actions проверяет протоколы, облачную функцию, тесты расширения и сборку Windows-помощника. Реальное переключение Bluetooth и запуск голоса необходимо проверить на самом ПК.
