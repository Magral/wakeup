# Облако Wake Mini 1.5.3 — диагностика Алисы

Обновите только существующую облачную функцию ZIP-архивом WakeMini-Alice-Cloud-1.5.3.zip. Сохраните все переменные окружения; обработчик main.handler, Python 3.12. Windows-помощник 1.5.2 и Android менять не нужно. Навык заново привязывать не требуется.

Исправлено: HTTP-обработчик больше не выдаёт неверную авторизацию 401 при временном отказе сервиса проверки аккаунта. Для этого случая возвращается 503. Неверные токены и чужие аккаунты по-прежнему отклоняются. В нативном режиме временная недоступность остаётся ошибкой сервера. Эта правка не доказывает причину текущего сбоя пользователя.

Для проверки без облачных логов запустите Test-WakeMini-Cloud.ps1 на ПК: он спросит URL функции и путь к существующему wake.key. Ключ читается локально, передаётся только вашей функции по HTTPS и не выводится. Диагностика доступна только по этому ключу. Никаких команд выключения или запуска приложений она не отправляет.

Первая проверка измеряет DNS и подписанный ответ ПК из облака. Затем запустите сценарий Алисы и нажмите Enter: появится повторный отчёт. Отправьте вывод отчёта для разбора. При ошибке пришлите текст ошибки, без ключей и токенов. Если ссылка функции другая, скрипт намеренно не отправляет ключ.

Поля probe=pc_replied означают подтверждённую связь облака с помощником; DEVICE_UNREACHABLE — отсутствие подписанного ответа. В stages видны длительность авторизации и обмена с ПК, identity_unavailable/unauthorized/network_error. Обычные запросы сохраняют только имена этапов, безопасные коды, UTC и время исполнения.

История последних 20 запросов хранится только в памяти одного экземпляра функции. Другой экземпляр или холодный старт могут вернуть пустую историю; это не доказывает, что запрос Алисы не приходил. Диагностика не измеряет время запуска функции и доставку ответа до Алисы. У платформы общий предел ответа три секунды: https://yandex.ru/dev/dialogs/smart-home/doc/ru/start

Пока выполняется проверка, HAPP можно отключить. Текущая версия не увеличивает таймауты и не ослабляет проверку подписи. Для отката выберите прежнюю версию функции.
