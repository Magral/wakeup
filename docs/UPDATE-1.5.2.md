# Wake Mini 1.5.2 — проверка совместимости с TUN

Замените только WakeMiniAgent.exe, предварительно завершив помощник через трей. Сохраните все файлы настроек и wake.key. Облако и Android обновлять не требуется. Расширение Chrome из 1.5.1 остаётся совместимым.

Ответы UDP отправляются через интерфейс, получивший запрос. Помощник получает индекс через IP_PKTINFO и задаёт IP_UNICAST_IF для отправки. Системные маршруты, настройки VPN и брандмауэра не изменяются. Отправки сериализованы; после каждой отправки настройка интерфейса сбрасывается.

На вашем ПК: включите TUN, удалите временный маршрут 91.78.221.109/32 на Ethernet, проверьте связь с мобильного интернета и сценарий Алисы. Совместимость с конкретными фильтрами HAPP требует этой проверки; сборка сама по себе её не доказывает.

Удаление временного маршрута в PowerShell администратора:

```powershell
Remove-NetRoute -DestinationPrefix "91.78.221.109/32" -InterfaceIndex 8 -PolicyStore ActiveStore -Confirm:$false
```

Если запись уже отсутствует, добавлять её заново не нужно. При проблеме верните EXE 1.5.1 и временный маршрут для телефона. CIDR-исключение телефона в HAPP для нового механизма не требуется.
