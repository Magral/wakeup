# Wake Mini 1.7.0: HDMI и навык «Стим»

## Обновить
В помощнике 1.6.0 нажмите «Проверить обновления». Либо замените EXE вручную, сохранив wake.key и JSON. Для новых голосовых функций загрузите WakeMini-Alice-Cloud-1.7.0.zip в существующую функцию, сохранив прежние переменные окружения. Android и расширение Chrome не менялись.

## HDMI
ПК — HDMI 1; смарт-приставка — HDMI 2. Существующее сопряжение LG сохраняется. Обновите устройства навыка умного дома; создайте сценарии «HDMI 1» и «HDMI 2» с соответствующим устройством → включить. ПК должен быть включён. Выбранный вход не меняет сохранённый вход автозапуска, не выключает приставку. Кнопки HDMI также доступны в трее.

## Навык «Стим»: дополнительная настройка
Это отдельный диалоговый навык, а не сценарий под каждую игру. Базовые команды Wake Mini продолжают работать без следующей настройки.

1. Создайте приватный бакет Yandex Object Storage. Публичный доступ не включать. Создайте сервисный аккаунт с доступом чтения/записи только к этому бакету и статический ключ. Задайте правило удаления объектов префикса wakemini-steam/results/ через 7 дней. Хранилище и вызовы облачной функции тарифицируются Яндексом по вашему тарифу; API нейросети не используется.
2. Добавьте в функцию переменные STEAM_BUCKET, AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY (ключ сервисного аккаунта). Не публикуйте ключи. Установка boto3 происходит из requirements.txt при сборке функции. Для работы навыка нужен быстрый доступ функции к хранилищу.
3. В Яндекс Диалогах создайте отдельный приватный разговорный навык «Стим», активационное имя «стим». Backend — та же функция. Настройте связку аккаунтов тем же OAuth-приложением, что используется действующей интеграцией Wake Mini. Добавьте идентификатор нового навыка в STEAM_SKILL_ID функции. Авторизуйтесь аккаунтом владельца, указанным в YANDEX_LOGIN.
4. В Windows откройте «Steam: библиотека и облако», укажите steam.exe и HTTPS-адрес функции functions.yandexcloud.net без параметров. Включите разрешение запуска игр, сохраните, обновите список. После успешной синхронизации в облаке появится каталог названий/AppID без путей к вашим файлам.
5. Скажите «Алиса, запусти навык Стим». На вопрос «Какую игру запустить?» назовите игру. Короткую фразу «Алиса, запусти Стим» проверяйте отдельно.

При необходимости задайте STEAM_ALIASES как JSON: {"275850":["космос","ноу менс скай"]}. Неточные совпадения подтверждаются пользователем или выбираются номером. No Man’s Sky имеет встроенные русские варианты.

## Как запускается игра
Облако сохраняет команду с AppID и сроком 10 минут, отправляет WOL. ПК проверяет облако каждые 5 секунд при включённой синхронизации. Помощник проверяет, что игра установлена, включает LG/выбирает HDMI 1, отправляет Steam rungameid. Если обнаружен процесс игры из её каталога — пытается вывести его окно без нового запуска. Автоматический вход в Windows и работа помощника необходимы. PIN/пароль Windows помощник не вводит.

Хранится одна ожидающая команда на этот ПК: новый выбор заменяет ещё не начатую предыдущую команду. После истечения срока игра не запускается. Идентификатор исполнения сохраняется локально до побочных действий: после сбоя/перезапуска незавершённая команда не повторяется автоматически. Для повтора дайте новую команду. Статус launch_requested означает принятие запроса Steam, а не подтверждение загрузки игры. Лаунчеры вне каталога игры и привилегированные окна могут не определяться/не выводиться на передний план.

## Проверка
HDMI 1/2 при включённом ПК. Затем навык при включённом и выключенном ПК, неоднозначное название, уже запущенная игра, удалённая игра, повторная доставка команды. До создания бакета/навыка сквозной запуск голосом недоступен. Автотесты проверяют каталог, протокол HDMI, поиск/уточнения, подписи и отбрасывание завершённых/просроченных команд; реальную загрузку ПК, Steam и LG нужно проверить дома.
