# Wake Mini 1.7.3 — приглушение игр во время «Атласа»

При запуске фонового голосового разговора «Атлас» помощник уменьшает громкость аудиосеансов игр Steam вдвое относительно их исходного уровня: 80% → 40%, 100% → 50%. Общая громкость Windows, микрофон и голос Chrome не меняются.

Повторная команда «Запусти Атлас» не уменьшает громкость повторно. Помощник проверяет игровые аудиосеансы каждые 750 мс во время разговора, включая появившиеся после запуска разговора и перехода HDMI / FreeBuds. Игры определяются по расположению исполняемого файла в установленных каталогах библиотеки Steam, настроенной в помощнике (или автоматически найденного Steam). Игры вне этой библиотеки и защищённые процессы, путь которых Windows не позволяет прочитать, не затрагиваются. Вывод игры в эксклюзивном аудиорежиме может не поддерживать управление через микшер Windows.

При завершении голосового режима, закрытии браузера/потере связи с расширением, выходе из помощника или неудачной подготовке разговора приглушение снимается автоматически. Недоступные в этот момент аудиосеансы восстанавливаются, когда снова появляются. Если пользователь сам изменил громкость игры в микшере во время разговора, помощник оставляет выбранный уровень.

Исходные уровни сохраняются рядом с EXE в wake-audio-ducking.json до изменения микшера. Это журнал восстановления, не ключ подключения. После аварийного завершения следующий запуск помощника попробует восстановить оставшиеся уровни. Не удаляйте журнал, пока уровни не восстановлены; после успешного восстановления он удаляется автоматически.

## Что обновить

Обновите только **помощник Windows до 1.7.3.0**: трей → «Проверить обновления…». Для ручной установки завершите помощник через трей и замените WakeMiniAgent.exe, сохранив wake.key и JSON. Облако остаётся 1.7.2: если оно уже обновлено до этой версии, повторно загружать архив не нужно. Android, навык, сценарии Алисы и расширение Chrome не менялись.

Приглушение действует в фоновом режиме голоса через расширение Wake Mini Voice. В режиме, который только открывает страницу для ручного запуска, приглушение не включается, поскольку помощник не получает подтверждение окончания разговора.

## Проверка на домашнем ПК

1. Запустите игру Steam со звуком.
2. Скажите «Алиса, запусти Атлас»: после готовности Chrome звук игры должен стать тише, голос — остаться обычным.
3. Повторите команду: игра не должна стать ещё тише.
4. Завершите голосовой разговор штатной кнопкой: громкость игры должна восстановиться автоматически.
5. Проверьте переход HDMI / FreeBuds и запуск новой игры во время разговора.

Автоматические проверки покрывают относительную громкость, повторный вызов, миграцию, новые игры, ручные изменения микшера, журнал до изменения Windows, восстановление после завершения/перезапуска/выхода, прежние протоколы и сборку Windows. Реальный микшер игры и FreeBuds требуют проверки на вашем ПК.
