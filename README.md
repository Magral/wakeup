# Wake Mini

Минималистичная Android-утилита для Wake-on-LAN. Приложение формирует стандартный magic packet и отправляет его на заданный IPv4 broadcast-адрес и UDP-порт. MAC-адрес и сетевые параметры сохраняются локально на устройстве.

## Сборка

Откройте папку `WakeMini` в Android Studio с Android SDK Platform 35 и выполните **Build > Build APK(s)**. Проект не использует сторонние Android-библиотеки.

## Настройка ПК

1. Включите Wake-on-LAN в BIOS/UEFI и в свойствах сетевого адаптера операционной системы.
2. Узнайте MAC-адрес Ethernet-адаптера ПК.
3. Подключите телефон и ПК к одной локальной сети. Для обычной домашней сети сначала попробуйте broadcast `255.255.255.255` и UDP-порт `9`.
4. Некоторые роутеры блокируют широковещательные UDP-пакеты или требуют адрес подсети, например `192.168.1.255`. Wi‑Fi с изоляцией клиентов тоже может мешать.

Отправка magic packet сама по себе не проверяет, включился ли компьютер. Для пробуждения из внешней сети потребуется отдельная настройка роутера или VPN.
