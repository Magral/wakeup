# Wake Mini

Минималистичная Android-утилита для Wake-on-LAN. Приложение формирует стандартный magic packet и отправляет его на заданный IPv4-адрес или DDNS-имя и UDP-порт. MAC-адрес и сетевые параметры сохраняются локально на устройстве.

## Сборка

Откройте папку `WakeMini` в Android Studio с Android SDK Platform 35 и выполните **Build > Build APK(s)**. Проект не использует сторонние Android-библиотеки.

## Настройка ПК

1. Включите Wake-on-LAN в BIOS/UEFI и в свойствах сетевого адаптера операционной системы.
2. Узнайте MAC-адрес Ethernet-адаптера ПК.
3. В одной домашней сети сначала попробуйте broadcast `255.255.255.255` и UDP-порт `9`. Если не сработает, укажите broadcast вашей подсети, например `192.168.1.255`.
4. Для удалённого пробуждения безопаснее подключить телефон к домашней сети через VPN, настроенный на роутере, и отправлять пакет на broadcast домашней подсети. Сам VPN должен пропускать или перенаправлять WoL-пакет в локальную сеть; простое подключение к VPN не гарантирует пересылку broadcast.
5. Альтернатива — встроенная функция WoL на роутере: укажите внешний IP/DDNS и UDP-порт, который роутер настроен принимать для этой функции. Обычная переадресация порта непосредственно на выключенный ПК может не сработать, потому что роутер не знает его MAC-адрес для доставки пакета. Возможности зависят от модели роутера.

Wake-on-LAN нужно включить в BIOS/UEFI и настройках сетевой карты. Отправка magic packet сама по себе не подтверждает, что компьютер включился.
