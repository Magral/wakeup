# Wake Mini

Компактная Android-утилита для Wake-on-LAN с круглой кнопкой-виджетом на главном экране. Нажатие на виджет само выполняет переключение: если Windows-помощник доступен, отправляет защищённую команду выключения; если ответа нет, отправляет magic packet для включения.

## Сборка Android-приложения

Версия 1.1.3 показывает индикатор связи: зелёный, если Windows-помощник отвечает, красный, если ответа нет. Проверка идёт при открытом приложении раз в 15 секунд и по нажатию «Проверить». Настройки сохраняются автоматически на телефоне.

Откройте папку `WakeMini` в Android Studio с Android SDK Platform 35 и выполните **Build > Build APK(s)**. Сторонние Android-библиотеки не используются.

## Настройка компьютера и роутера

1. Подключите ПК к роутеру кабелем Ethernet. Включите Wake-on-LAN в BIOS/UEFI и в свойствах сетевого адаптера Windows.
2. На Archer AX1800 закрепите за ПК постоянный IP. В правилах перенаправления UDP-порта направьте порт `3000` на этот IP. Внешний адрес/DDNS и порт `3000` используйте в приложении.
3. Скачайте `WakeMiniAgent.exe` из GitHub Release и положите его в отдельную папку, например `C:\\WakeMini`.
4. Один раз запустите `Allow-WakeMini-Firewall.bat` и подтвердите запрос Брандмауэра Windows. Это разрешает входящие UDP-пакеты помощнику на порту `3000`.
5. Запустите `WakeMiniAgent.exe`. При первом запуске он создаст рядом файл `wake.key` и покажет 64-символьный ключ. Введите этот ключ в Wake Mini на телефоне. Не передавайте ключ другим людям.
6. Для автозапуска помощника создайте ярлык `WakeMiniAgent.exe` в папке автозагрузки Windows: нажмите Win+R, введите `shell:startup` и поместите туда ярлык. Новая версия запускается сразу в области уведомлений рядом с часами.
7. Щёлкните правой кнопкой по значку Wake Mini в трее → **Настроить приложение**. Выберите файл `.exe`. Можно добавить параметры запуска и включить запуск приложения при входе в Windows.
8. В приложении укажите MAC проводного адаптера ПК, DDNS-имя роутера, UDP-порт `3000` и ключ. Затем добавьте виджет Wake Mini на главный экран телефона.

## Поведение кнопки

- Если помощник отвечает с правильным ключом, приложение просит Windows выключить ПК через 10 секунд.
- Если ответа нет, приложение отправляет Wake-on-LAN пакет. Это сработает, когда ПК выключен или спит, а роутер и сетевой адаптер настроены на WoL.
- Если помощник остановлен или порт закрыт, включение может сработать, а выключение — нет. Для переключения помощник должен быть запущен на ПК.

Помощник принимает только проверку состояния и команду выключения с HMAC-подписью и одноразовым запросом. Он не выполняет произвольные команды. Если провайдер использует CGNAT, проброс порта извне может быть недоступен.

## Управление через Алису без Home Assistant

Приватный навык «Умный дом» управляет компьютером через Yandex Cloud: включение, выключение, перезагрузка, сон и запуск выбранного приложения. Windows-помощник запускается в трее; выбранное приложение можно запускать при входе в Windows. APK Android обновлять не нужно.

В «Доме с Алисой» можно создать голосовой сценарий, который включает ПК. Если в настройках Wake Mini включён автозапуск выбранного приложения, оно откроется после загрузки Windows.
